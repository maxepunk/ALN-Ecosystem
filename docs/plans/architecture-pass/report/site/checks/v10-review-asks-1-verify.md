## Result

Every one of the 34 problems is real. The review's code facts are accurate; I found no wrong line reference. 14 changes stand as proposed. 20 need a different change, and inside those I refuse seven parts:

1. C-2's route. It turns the pack half of the owner's question C into an agent's call. The glossary contradicts the reading it would rest on (`CONTEXT.md:217-227`), so the tests for a call are not met. It stays the owner's, with a recommendation.
2. F-3 and I-4 part 4. They add "may anyone run the tests on the show machine during a game" to the owner's question F. That is about how the work runs, so it fails the first test.
3. E-2's wording. "An add-on runs as its own program and holds a pass" is how to build it. The outcome can be stated without it.
4. B-1's two extra asks. "Which you want for ALN" is a production's setting and no decision ahead waits on it. "May the engine require a second machine in every kit" is answered by the owner's decision on what is fixed, so it is a reading to confirm.
5. B-2's option of a new ask inside A. The TV clock belongs in the review of the target that proposes it.
6. D-2's two claims: that today's rules "cannot read the game's state" (they read a sale's points and the team's score), and that rules changing scores "change your ruling of 2026-07-09" (that ruling is about who may act; whether it covers a designer's rule is the owner's to say).
7. F-4's "For you" sentence. Nothing in the record says the owner works the show.

Two things change what the owner decides and the review missed them: a spare machine cannot bring the room back by itself (V-1), and the site says abilities are "only ever added" where the glossary allows removal at a major version (V-2).

Severity: I agree with the review's grades except B-1, which I rate medium. Its options already state what the players lose; the harm comes from B-2, B-3 and V-1.

## Missed by the review (mine)

**V-1 (medium, close to high). A spare cannot bring the room back by itself.** B `options[1].means` says a spare "takes over at once" and "The players lose a minute". The review's third level says "The room comes back by itself ... with no action by a GM". Neither is true of the kit. The TV hangs on the show machine's HDMI output (`displayControlService.js:5-12`), the sound leaves by the same machine (Design: "drives the TV over HDMI and the room's sound"), and the lighting system runs on it too (`backend/CLAUDE.md:126`, `:427`: Home Assistant in a container at `localhost:8123`). A second machine can take the game and the devices by itself. The TV, the speakers and the lights need a moved cable, a switched input or duplicate equipment. The owner would choose the dearest level for a promise it cannot keep. Change: the B-1 levels above, which split "the game comes back" from "the room comes back".

**V-2 (medium). "Abilities are only ever added" is stronger than the record.** `groups[0].intro[2]`, C `evidence[7]` and QT21's status say an ability is "only ever added, never removed". The glossary says ability names are append-only, and that "removing one is a major engine version" (`CONTEXT.md:219-221`), and that a breaking change to the pack's format requires an exact match (`:225-227`). So the record allows an old pack to stop opening in two ways. The page concludes "so an old pack runs on a new engine". Change: with C-2 the conclusion goes. In QT21's status replace "an ability is only ever added, never removed" with "ability names are only added within a major version of the engine; removing one is a major version". Whether old packs must always open is then the owner's, in C.

**V-3 (medium). The second show machine is given four jobs that exclude each other.** The roadmap makes it the holder of the last release for a rollback, then the standing test machine (`ROADMAP.md:461-475`). EX17 builds each new release on it. B-3 makes it tonight's spare. F-2 makes it the host of the design tool and trial copies. A spare must carry tonight's release, a rollback machine the last one, a test machine the next one. The review leans on the machine in B-3 and F-2 and never says so. Change: the sentences added in B-3 and F-2 above, and one line in B `evidence[4]` or I: "One second machine cannot be the spare, the rollback and the test machine on the same night.
