# Agent briefs (the record of what each subagent was asked)

One file per dispatched brief, dated. A brief is the single source of
requirements for the agent it was written for (docs/agents/process.md
§3 and rule 7b); keeping it here lets a cold agent see exactly what a
census, review, or task was asked to do, and lets a later run repeat it.
Paths inside a brief may name the scratchpad of the session that wrote
it; the repo copy is the durable one.
