## 1. Mechanism (ruling R-5-1): current phase is DERIVED — "latest satisfied start" — overtime generalized

1. **Phase runtime lives in gameClockService** (the master time authority; mirrors setOvertimeThreshold): `setPhases(phases|null)` injected by sessionService at startGame from `getClockRules().phases` — a NEW normalized field (declared array, or null when the pack declares none/unusable; the four toEqual pins update in lockstep). **Inert rule:** with null OR exactly one declared phase, the machinery is INERT (current phase stays null, nothing ever emits) — the degenerate case IS "no phase structure" (B11's own words), so ALN behavior and wire state stay effectively unchanged and the packless/legacy fallback needs no synthetic phase.
2. **Uniform current-phase rule:** current = the LAST phase in DECLARED ORDER whose start is satisfied — `{at}` satisfied when elapsed ≥ at; `{trigger}` satisfied once its event is observed while the clock is RUNNING. Evaluated at start() with NO emission (initial state; possibly null if nothing is satisfied at 0 — legal), re-evaluated on every tick and on every observed trigger; each CHANGE after start() emits `phase:changed {phaseId, label, previousPhaseId, elapsed, via: 'time'|'trigger'}`. One emission per LANDING: a trigger that lands past not-yet-entered intermediate phases skips them silently — declared-order skip-forward is the same rule restore uses, so live and restore semantics cannot drift. Pause: elapsed freezes ⇒ time phases freeze automatically; trigger observation is gated on status === 'running'.
3. **Persistence/restore (E1):** `toPersistence()` gains `phaseId`; `restore()` re-seats it (unknown id → warn + null), then marks the latest later-in-order TIME phase satisfied by the restored elapsed as current WITHOUT emitting — the same mark-don't-fire as overtime and clock-cues. Triggers that fired during downtime are lost by definition (matches cue semantics: events during downtime don't exist).
4. **Delivery — NO new discrete wire event.** `phase:changed` is a backend EventEmitter event only. broadcasts.js adds it to the gameclock service:state push triggers; `getState()` and `buildGameClockState()` (both fallback returns included) gain **required-nullable `phase: {id, label} | null`**; contracts change FIRST (DomainStateGameclock + the line-2324 prose + sync:full gameClock component + openapi GameState + both hand-built contract fixtures). No MESSAGE_TYPES / subscribe-oneOf change — the three-way lockstep stays untouched.
5. **Cue trigger:** cueEngineWiring forwards gameClockService `phase:changed` → `handleGameEvent` (the gameclock:started pattern); the normalizer joins **ENGINE_EVENT_NORMALIZERS** (clock machinery emits it — phase ids being pack data doesn't move the table, exactly as tokenIds ride transaction payloads) with fields {phaseId, previousPhaseId, label, elapsed, via} → cue conditions like `phaseId eq the-job` (B11's "cue conditions" satisfied). Config-tool TRIGGER_EVENTS gains the mirrored row (the F-TOOL-09 hand-mirror debt is extended knowingly, not fixed here).
6. **Trigger observation seam:** the same cueEngineWiring registrations that feed handleGameEvent also feed `gameClockService.handlePhaseTrigger(eventName)` through one local dispatcher — the single wiring file remains THE seam, re-registered by the existing central post-reset wiring points.
7. **Gate flip + residual validation** (the D1s2 refusal retires for driven shapes; three residual rules): duplicate phase ids → flavor-i ("self-contradictory"); a time-started phase whose `at` ≤ an earlier-declared time-start's `at` → flavor-i (unreachable under the declared-order rule); `start.trigger` outside the engine's merged EVENT_NORMALIZERS key set (minus `phase:changed` itself) → flavor-ii drivability refusal naming the event. Absent/empty/degenerate keep passing; the language-rule and null-safety pins retarget to the residual refusals. No new ENGINE_CAPABILITIES id — structural gates are the slice-0→3 precedent.
8. **Scanner display:** the MonitoringDisplay adapter threads `phase` through; SessionRenderer renders the pack label in a NEW `#game-clock-phase` element beside the clock (never inside `#game-clock-display` — 07d-03's MM:SS parse contract holds), hidden when phase is null. ALN (degenerate ⇒ null) renders byte-identical; the toy GAINS its phase label — the 3c pattern ("ALN byte-visual-identical; toy BECOMES styled"). Standalone stays clock-less (recorded, not changed).
9. **Fixtures:** the toy restores `casing`@0 + `the-job`@1800 AND — the 3c Contraband precedent: the dual-pack gate must exercise BOTH start kinds — gains `the-getaway` ("The Getaway") trigger-started on `group:completed`, declared last; manifest regen.
